# modorin
설치나 빌드 없이 동작하는 개인 프로젝트 포트폴리오입니다. index.html을 브라우저로 열 수 있습니다.

## 내용 변경
- projects.js: 프로젝트 이름, 설명, 분류, 실제 배포 URL을 입력합니다. 빈 URL에는 링크 준비 중이 표시됩니다.
- index.html: 소개와 수상 기록을 수정합니다. 현재 수상 정보는 미입력 상태입니다.
- 방문자 카운터는 실제 통계 서비스 미연결 상태로 TODAY / TOTAL에 대시를 표시합니다. 로컬 방문 횟수를 전체 방문자 수로 표시하지 않습니다.
- 실제 집계 권장안: GoatCounter 사이트를 생성하고 발급된 추적 스크립트를 연결합니다. TODAY는 Asia/Seoul 당일, TOTAL은 집계 시작 이후 누적으로 정의합니다. 공개 사이트에 숫자도 표시하려면 Cloudflare Worker 등의 서버에서 GoatCounter API를 조회하고 캐시한 읽기 전용 통계 응답을 제공합니다. API 토큰은 Worker 비밀 변수에 보관하며 정적 사이트에는 넣지 않습니다. 계정과 사이트 식별자가 아직 제공되지 않아 추적은 활성화하지 않았습니다.
- Awards 항목은 실제 수상이 아닌 명시적인 형식 예시입니다. Studies에는 아직 실제 학습 노트가 없습니다.
- 프로젝트 상세에는 기존 인터페이스 콘셉트와 설명을 보존했습니다. 실제 스크린샷과 확인된 기술 정보는 추후 추가합니다.

## GitHub Pages 배포
파일을 main 브랜치에 올리고 저장소 Settings → Pages → Source에서 GitHub Actions를 선택합니다. 포함된 워크플로가 정적 파일을 배포합니다. 배포 성공 후 제공되는 주소로 누구나 설치 없이 접속할 수 있습니다.

## 로컬 확인
저장소에서 `python3 -m http.server 8000 --bind 127.0.0.1`을 실행해 HTTP로 확인할 수도 있습니다. 별도 패키지는 필요하지 않습니다.
